# 抖音无水印超清视频下载插件 (Douyin Video Downloader)

一款专为 Chrome 浏览器打造的现代化抖音网页版无水印视频下载扩展，采用 Manifest V3 架构，具备多层嗅探拦截与智能解析能力。

---

## ✨ 核心功能与亮点

1. **无水印 4K 极清 / 2K 超清 / 1080P 多清晰度智能嗅探**
   - 深度解析抖音 CDN 传输链路与播放器内核 (XGPlayer/WestMelon)，直接捕获最高达 4K (2160P)、2K (1440P)、1080P 等原生最高码率无水印直链，支持 H.265 / ByteVC1 / H.264 多格式。
2. **播放器原生悬浮面板与清晰度下拉切换**
   - 无论是在抖音首页推荐流、单个视频详情页，还是用户个人主页，播放器右上角均会自动注入精致的毛玻璃悬浮操作胶囊。
   - 胶囊按钮智能识别并高亮显示当前视频最高画质（如 `4K 极清 ▾`），点击可展开完整画质下拉菜单自由选择下载。
3. **快捷键一键秒下**
   - 浏览抖音时，直接按下键盘字母键 **`D`**，即可直接秒下载当前正在播放的最高画质视频！
4. **扩展弹窗面板 (Popup)**
   - 点击浏览器右上角插件图标，即可浏览当前标签页捕获的所有视频列表，展示视频封面缩略图、作者信息、视频文案、视频时长，支持画质选择、单选下载、复制直链、新标签页预览及一键批量打包下载。
5. **智能文件名净化**
   - 自动生成合规文件名：`Douyin_Videos/【作者昵称】视频描述_清晰度_视频ID.mp4`，自动过滤操作系统非法字符，方便下载归档。
6. **多层嗅探与双向容灾保障**
   - **MAIN World API Hook**：深度拦截抖音 `fetch` 与 `XHR` 原始接口数据，解析全清晰度视频源。
   - **XGPlayer 内核直通**：直接从播放器实例提取西瓜播放器 definitionList，确保 4K 真实源零遗漏。
   - **DOM 视口感知**：精准跟踪活跃播放器节点与滚动切换。
   - **Service Worker WebRequest 兜底**：全自动捕获 `*.douyinvod.com` 媒体流。

## 🚀 安装使用指南（3步快速上手）

### 第一步：打开 Chrome 扩展管理页面
在 Chrome 浏览器地址栏中输入以下地址并按回车：
```text
chrome://extensions/
```

### 第二步：开启「开发者模式」
在扩展页面右上角，找到并打开 **「开发者模式」** 开关。

### 第三步：加载已解压的扩展程序
1. 点击左上角的 **「加载已解压的扩展程序」** (Load unpacked) 按钮。
2. 在弹出的文件选择器中，选择本扩展所在文件夹：
   ```text
   D:\antigravity\douyin-downloader-extension
   ```
3. 点击「选择文件夹」，插件即刻安装完毕并生效！

## 🎬 使用方法

1. 打开 [抖音网页版 (douyin.com)](https://www.douyin.com)。
2. **方式一（悬浮胶囊）**：鼠标移动到视频播放区域，右上角会出现「1080P 无水印」浮动卡片，点击「下载」即可开始下载。
3. **方式二（快捷键）**：正在观看视频时，直接按下按键 **`D`** 即可触发下载。
4. **方式三（工具栏弹窗）**：点击 Chrome 顶部工具栏中的插件图标，弹出面板将展示浏览过的所有视频列表，支持一键批量下载或单独复制链接。

## 📂 项目结构说明

```
douyin-downloader-extension/
├── manifest.json       # Chrome 扩展配置 (MV3)
├── background.js       # 后台服务工作线程 (网络嗅探兜底、chrome.downloads 下载调度)

├── content.css         # 浮动按钮与Toast样式 (抖音深色/毛玻璃质感)
├── injected.js         # 页面级 Hook 脚本 (拦截 Fetch/XHR，提取高码率无水印直链)
├── popup.html          # 工具栏弹出面板布局
├── popup.css           # 弹窗样式表
├── popup.js            # 弹窗逻辑控制器 (视频列表渲染、批量下载、复制直链)
├── icons/              # 扩展图标 (16x16, 48x48, 128x128)
└── README.md           # 使用说明与开发文档
```
